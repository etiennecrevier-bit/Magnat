The portraits of the event cards' characters, one PNG per character, named after the character's `id` in `src/content/events.json`: `gilles.png` for `"character": { "id": "gilles", … }`. `src/ui/portraits.ts` collects every `*.png` here when the game builds, so adding a file is enough. The card shows it in a square, so a square image of at least 192 × 192 pixels works best. A character with no file here gets a cream silhouette instead.
