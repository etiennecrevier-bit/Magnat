The portraits of the event cards' characters, one PNG per character, named after the character's `id` in `src/content/events.json`: `gilles.png` for `"character": { "id": "gilles", … }`. `src/ui/portraits.ts` collects every `*.png` here when the game builds, so adding a file is enough. The card shows it in a square at 96 px, so save a real PNG (not a JPEG renamed `.png`) of 512 × 512 pixels; `src/ui/portraits.test.ts` rejects one larger than 512 × 512 or heavier than 400 KB, and a character on a card with no file unless it is listed in `AWAITING_PORTRAIT`. A character with no file here gets a cream silhouette instead.
