The portraits of the event cards' characters, one PNG per character, named after the character's `id` in `src/content/events.json`: `gilles.png` for `"character": { "id": "gilles", … }`. `src/ui/portraits.ts` collects every `*.png` here when the game builds, so adding a file is enough. The card shows it in a square at 96 px, so save a real PNG (not a JPEG renamed `.png`) of 512 × 512 pixels; `src/ui/portraits.test.ts` rejects one larger than 512 × 512 or heavier than 400 KB, and a character on a card with no file unless it is listed in `AWAITING_PORTRAIT`. A character with no file here gets a cream silhouette instead. The candidates to hire have theirs here too, named after their `portrait` id in `src/content/staff.json` (`amelieGagnon.png` for Amélie); « Équipe » shows a hired one's at 48 px, as the hiring list does every candidate's, their messages (hired, let go, underpaid, quitting) show it at 44 px, and `portraits.test.ts` checks that every candidate has one. `mmePrudhomme.png`, the banker's, is also the one « Le conseil de Mme Prudhomme » shows in the reports, at 64 px (`BANKER` in `src/ui/portraits.ts`). `realGingras.png` is Réal's, the tour's guide (`TUTORIAL.coach.character` in `src/content/tutorial.json`), which the tour's bubble shows at 64 px and his postcards at 44 px.
